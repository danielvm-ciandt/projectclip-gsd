<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Express proxy | Browser/SPA sends session cookies and auth requests to `/api/auth/*`; Express forwards to Neon Auth service |
| Express proxy → Neon Auth REST API | Server-to-server forwarded requests; Neon Auth is the authoritative session store |
| Neon Auth cookie → actorMiddleware | Session cookie returned by Neon Auth is forwarded from browser on every request; server calls Neon REST to validate |
| Agent → Bearer JWT | Agent processes present HMAC-signed JWTs; verified locally in actorMiddleware without Neon involvement |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | `resolveNeonAuthSession` | mitigate | Only trust session validation response from NEON_AUTH_BASE_URL; verify HTTPS required on that URL; never accept self-signed certs in production |
| T-02-02 | Spoofing | createNeonAuthProxyHandler | mitigate | Block `POST /api/auth/sign-up/email` with 403 in proxy handler (D-05 API gate); attacker cannot self-register via direct API call |
| T-02-03 | Tampering | Cookie forwarding in proxy | mitigate | Forward `Cookie` header verbatim; do not allow client to inject arbitrary `Cookie` fields beyond what the browser sends; parse with care |
| T-02-04 | Repudiation | Feature flag switching | accept | PAPERCLIP_AUTH_PROVIDER is an env var; changes require server restart; acceptable for internal deployment; log flag value at startup |
| T-02-05 | Information Disclosure | Neon Auth error responses | mitigate | Proxy handler strips verbose upstream error bodies before returning to client; return generic 401/403 with no internal details exposed |
| T-02-06 | Elevation of Privilege | actorMiddleware resolveSession bypass | mitigate | ASVS L1 V2.1 — ensure agent JWT branch (Bearer token check) short-circuits before session resolution; tested in Task 3 |
| T-02-07 | Denial of Service | Unbounded proxy forwarding | accept | Internal deployment only; no rate limiting required in Phase 2; add if exposed publicly in Phase 10 |
| T-02-08 | Tampering | PAPERCLIP_AUTH_PROVIDER env var | accept | Infrastructure-level concern; attacker with env access owns the server already; low risk for internal deployment |
</threat_model>
